# DeskNest · 桌屿 v0.1.1

DeskNest 是一款本地 Windows 桌面收纳与快捷启动工具。把常用应用、文件、文件夹和网页快捷方式集中到分区卡片中，支持搜索、收藏、置顶、撤销和备份恢复。

当前为早期 MVP，后续会继续更新，欢迎反馈使用问题和功能建议。

## 下载与使用

1. 在本页 Assets 中下载 `DeskNest-0.1.1-windows-x64.zip`。
2. 完整解压，双击文件夹内的 `DeskNest.exe`。
3. 点击「扫描桌面」选择项目，或直接从桌面、资源管理器拖入。
4. 点击卡片启动，拖到左侧分区分类。

支持 Windows 10/11 x64，无需安装 Python，无需账号。请保留 `_internal` 文件夹；GitHub 自动生成的 Source code 是源码，不是可执行程序。

## 本版内容

- 支持外部快捷方式、文件和文件夹批量拖入。
- 支持空分区、卡片区域、窗口留白和左侧分区拖入。
- 重复项目跳过，保留已有分类、收藏和置顶。
- 搜索中拖入后显示目标分区，整批添加可一次撤销。
- 补充开源说明、新手教程、更新记录和贡献指南。

## 更新旧版

先在旧版中备份，再通过「更多 → 退出 DeskNest」完全退出，完整解压并启动新版。使用默认数据目录时沿用原数据。

## 当前范围

收纳只保存引用，不移动、隐藏或删除原桌面文件。备份不含原文件内容、背景图片本体和桌面图标坐标。当前没有自动更新和代码签名。

使用说明见仓库 `docs/USAGE.md`，问题请在 Issues 反馈。DeskNest 自身源码采用 MIT 许可证，第三方组件遵循各自许可证。
