# DeskNest 新手使用教程

适用版本：v0.1.1。支持 Windows 10/11 x64。

## 1. 下载与打开

1. 打开 [发布页面](https://github.com/1CJA/DeskNest/releases/latest)。
2. 展开 Assets，下载 `DeskNest-0.1.1-windows-x64.zip`。`Source code` 是源码，不是免安装程序。
3. 右键 zip，选择「全部解压」，将整个 DeskNest 文件夹放到固定位置。
4. 双击 `DeskNest.exe`。无需安装 Python，也无需注册账号。

请保留 `_internal` 文件夹，不要单独复制 exe。如果 Windows 阻止运行，请核对下载来源和系统提示；本项目目前没有代码签名，不要求关闭系统安全防护。

## 2. 添加你的第一个项目

**方法一：直接拖入。** 从桌面或资源管理器选中快捷方式、文件或文件夹，拖到中间卡片区域。拖到左侧分区名称，可直接添加到指定分区。

**方法二：扫描桌面。** 点击「扫描桌面」，勾选需要添加的内容，选择分区并确认。快捷方式默认勾选，普通文件和文件夹需要手动选择。

项目只保存原路径，原文件保留。重复添加会跳过，不会重置已有分类、收藏或置顶。在「全部项目」中拖入时，项目会进入第一个分区，默认是「常用」。

## 3. 分类、搜索与启动

- 左侧「+」新建分区；选中分区后使用底部按钮重命名或删除。
- 拖动左侧分区调整顺序；拖动项目卡片到左侧分区改变分类。
- 单击卡片启动，或键盘选中后按 Enter。
- 搜索框按名称和路径搜索所有分区；Ctrl+F 聚焦搜索。
- 右键卡片可收藏、置顶、打开所在位置或移除引用。
- 拖动卡片到另一张卡片前可排序；搜索状态下不支持排序。
- Ctrl+Z 撤销最近整理操作，最多 30 步，重启后仍保留。

删除分区时，其中项目会转移到第一个保留的分区。移除项目卡片不会删除原文件。

## 4. 关闭、呼出与外观

关闭窗口后应用会驻留托盘。按 Ctrl+Alt+Space 或使用托盘菜单重新打开；如快捷键被占用，使用托盘入口。

需要完全退出时，使用「更多 → 退出 DeskNest」。在「更多」中还可以切换主题、调整图标大小、设置背景和启用开机启动。开机启动默认关闭。

## 5. 备份与升级

1. 更新前在「更多 → 立即备份 / 导出备份」保存布局。
2. 在旧版本中使用「更多 → 退出 DeskNest」，仅关闭窗口不会退出。
3. 下载新版，完整解压到新文件夹并启动。使用默认数据目录时会沿用原数据。
4. 如需恢复，使用「恢复本地备份 / 从文件恢复」。恢复前会自动备份当前状态。

默认数据目录：`%LOCALAPPDATA%\DeskNest\`。卸载免安装程序不会自动清除此目录。

备份包含分区、项目路径、排序、收藏、置顶和设置，不包含原文件内容、背景图片本体或桌面图标坐标。路径依赖本机，备份不适合作为跨电脑文件迁移工具。

## 常见问题

**为什么桌面图标还在？** 当前版本是引用收纳工具，不会移动或隐藏原桌面图标。

**为什么拖不进去？** 请正常权限运行应用；Windows 会阻止普通资源管理器向管理员权限的应用拖入。支持本地文件路径，不支持「此电脑」「回收站」等虚拟图标或浏览器地址拖入。

**为什么点击后提示文件不存在？** 原文件可能被移动或删除。移除失效引用，再从新位置拖入即可；应用不会猜测替代路径。

**打不开、闪退或出现异常怎么办？** 保留 `%LOCALAPPDATA%\DeskNest\desknest.log`，在 [Issues](https://github.com/1CJA/DeskNest/issues) 中说明应用版本、Windows 版本、操作步骤和报错。发送日志前检查个人路径；不要公开数据库或私人文件。

**如何获取后续更新？** 关注仓库的 Releases 和 [更新记录](../CHANGELOG.md)。当前没有自动更新功能，需要手动下载新版。
