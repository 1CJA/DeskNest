# MVP 验证记录

验证日期：2026-10-22（北京时间）。环境：Windows 10 x64、Python 3.12.10、PySide6 6.12.0。

## 已验证

- 26 项自动测试全部通过：默认分区、持久化、扫描不修改文件、扫描选择、单击卡片调用启动、全局搜索、拖入分区、删除分区保留项目、持久撤销、原快捷方式启动、重复导入保留分类与标记、损坏/错误备份拒绝、替换失败保留数据库、备份恢复闭环。
- 读取真实 Windows 桌面位置并扫描成功，没有读取错误。
- 原生 Windows 窗口正常显示中文；浅色、深色及包含四种样本项目的卡片已截图检查。
- 通过真实 .lnk 启动测试命令，确认快捷方式参数和工作目录得到保留。
- 原生窗口系统托盘可用，Ctrl+Alt+Space 注册成功。
- 源码应用使用独立数据目录启动、渲染、退出成功。
- 打包后的 DeskNest.exe 使用独立数据目录启动成功，生成默认 6 个分区，渲染窗口后以退出码 0 结束。报告保存在 test-data/frozen-smoke.json。

## 0.1.1 桌面拖入修复

- 新增 11 项 Qt 拖放测试，通过实际控件的事件分派检查拖入卡片区域、空分区、空库、窗口留白、左侧指定分区与「全部项目」。
- 多文件和中文/空格路径可批量添加；搜索时拖入会显示目标分区；快捷方式保留原路径供启动。
- 外部文件拖放返回 CopyAction，包含用户按 Shift 请求移动的场景；仅允许移动的来源被拒绝。测试确认原文件及文件夹内容仍在，整批可一次撤销。
- 重复路径不改变已有分区、收藏、置顶；无法读取路径会提示，正常部分仍可添加；数据库失败不生成成功提示、不改动源文件。
- HTTP 地址、无本地路径的虚拟图标被拒绝；内部卡片排序、分区排序及跨分区移动仍然工作。
- 修正测试窗口清理顺序，测试结束后进程退出码为 0。
- 0.1.1 打包程序已使用独立测试目录打开原生窗口，显示新版拖入提示和中文，退出码 0；日志无错误。报告：`test-data/frozen-drop-0.1.1.json`。

## 验证边界

拖放自动化通过 Qt 本地文件 URL 事件模拟桌面/资源管理器输入，尚未执行真实鼠标从 Explorer 拖入的端到端验收。

自动化中的普通应用启动使用 mock，真实 Windows 启动额外以项目内生成的测试快捷方式验证；没有批量启动用户桌面上的程序。

未实际修改本机开机启动项或重启系统验收；启动命令的源码/打包路径组成已检查。OneDrive/重定向桌面通过 Windows Shell 路径接口支持，尚未在专门的重定向桌面机器上验收。

参考图片、样本数据库、启动标记和日志保存在 test-data，均不应提交 Git。发布包没有代码签名，未在所有 Windows 版本或干净虚拟机上测试。
